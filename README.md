零配置、离线运行的 QQ NT 本地聊天记录备份导出工具，自动定位本地数据库，支持 TXT / 单文件 HTML / PDF 导出，渲染图片与表情，读取 WAL 日志获取最新本地消息。

> ⚠️ 免责声明
> 本工具**仅用于导出当前本机、当前登录用户自己已经缓存到本地的聊天数据**，仅做个人本地备份用途。
> 本项目不提供、不支持远程获取他人数据，不用于绕过任何权限验证；使用本工具产生的一切后果由使用者自行承担。
> 仅在你拥有对应聊天数据所有权、符合软件用户协议与当地法律法规的前提下使用。

## ✨ 特性
- 🖱️ **零配置**：从 `UserDataInfo.ini` / 注册表自动定位本地数据库
- 🔑 **自动化凭证读取**：自动读取本机运行环境内可访问的数据库凭证
- 📄 **三种导出格式**：
  - TXT：简洁文本备份
  - HTML：独立单文件，自带样式
  - PDF：基于 Chrome/Edge CDP 协议无头打印，中文、Emoji 渲染正常
- 🖼️ **媒体渲染**：通过 protobuf 解析读取本机缓存资源，渲染图片、表情；本地缓存缺失时，生成媒体诊断清单 `*.未定位媒体.txt` 供自查
- 🆕 **数据完整性**：读取主数据库 + WAL 预写日志，包含未落盘的本地最新消息
- 📕 **移动端友好排版**：560px 居中气泡对话布局，区分发送方向

## 🚀 快速开始
1. 下载 `QQ聊天记录导出工具.exe`，与 `get_qq_key.ps1` 放在同一目录
2. 双击运行 → 填入目标本机登录 QQ 号 → 自动获取凭证 → 加载联系人列表并选择对象
3. 选择导出格式（HTML / PDF / TXT），指定保存路径，等待完成
> 无需额外配置 PowerShell

## 📂 目录

```
QQ聊天记录导出工具.exe            # 打包后的可执行文件
get_qq_key.ps1                 # 运行时密钥提取脚本
src/                           # 源码
  ├── qq_pdf.py                # HTML/PDF 导出 + 消息解析
  ├── cdp_pdf.py               # Chrome DevTools Protocol 打印 PDF
  ├── entry.py                 # 启动器（加载原始字节码 + 打补丁）
  └── build.spec               # PyInstaller 打包配置
```


## ⚠️ 限制

- 商城表情若本地无缓存会降级为 `[动画表情]` 文字；视频不抽帧。
- 约 0.7% 的消息属于 QQ 本机未缓存（原图未下载 / 表情走 CDN），无法离线补全。
